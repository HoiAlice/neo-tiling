# BOX at d = 2: final statement, proofs, algorithm

This file supersedes BOX.md, BOX-THEOREM.md where they differ. In particular the delta-enlargement of BOX-THEOREM.md is no longer needed (Theorem 1 below is exact for the closed box), and the remark there that a closed-box witness "need not be rational" is withdrawn: Theorem 3 gives a rational witness inside the closed box.

## 0. Statement

Data: rational L, U in R^{T x 2}_{>0}, L <= U coordinatewise (zero-width coordinates, even L = U, allowed); rational y in R^T_{>=0}. box_t = [L_t, U_t].
BOX(L,U,y): exists Q with L <= Q <= U and `WeakSolvable Q y`.
Corner configuration W = (L_1,...,L_T,U_1,...,U_T) (2T points of R^2_{>0}, duplicates allowed). a_t := L_t, b_t := U_t (the indices t and T+t of W).
C(W) = `indicatorCone (weakReachableSpectra W)`: cone generated by indicators of weakly reachable subsets of the index set of W.

**Theorem 1 (exact).** BOX(L,U,y) <=> LP: there is w in C(W) with w(a_t) >= y_t >= w(b_t) for all t.
**Theorem 2 (algorithm, complexity).** LP is a linear feasibility problem with O(T^3) variables and O(T^2) rows (Sec. 3); BOX is decided exactly in time polynomial in T and the bit length of (L,U,y). No auxiliary parameter, all numbers rational of input size.
**Theorem 3 (witness).** If BOX holds, an explicit rational Q in [L,U] with y weakly solvable at Q is computed from an LP solution.
**Theorem 4 (dominance only, any d, arbitrary boxes).** exists Q in [L,U] with `forall s t, y_t < y_s -> exists i, Q_{s,i} <= Q_{t,i}` iff for all s,t with y_t < y_s some i has L_{s,i} <= U_{t,i}. Explicit witness, O(d T^2).
**Theorem 5 (rho_inf).** For boxes depending monotonically and continuously on a scale kappa (e.g. [P/kappa, kappa P]), the minimal feasible kappa is attained and is a root of one of O(T^3) explicit polynomials of degree <= 4; computed by sorting these and O(log T) exact LPs.

## 1. Inputs used, with their exact scope

(F1) `NeoTiling.weakSolvable_iff` (NeoTiling/Closure.lean): for d >= 2, P >= 0, y >= 0: `WeakSolvable P y <-> y in indicatorCone (weakReachableSpectra P)`. `WeakSolvable P y` is `P in closure {Q | (forall t, Q t in orthant d) /\ NeoSolvable Q y}`; hence for fixed y the set {Q : WeakSolvable Q y} is closed. `IsWeakReachable P S := forall t in S, exists xi >= 0, xi != 0, forall s not in S, 0 <= xi . (P s - P t)`. No hypothesis on duplicates or collinearity.
(F2) `NeoTiling.PolyHardness.mem_indicatorCone_iff_flow (b := false)` (poly-hardness/lean/PolyHardness/FlowLP.lean), with `isReachableB_false_iff` (IsReachableB false = IsWeakReachable): for EVERY `P : Fin T -> Fin 2 -> R` (no positivity, injectivity or general-position hypothesis; the section variable is just `P`), y in indicatorCone (weakly reachable sets of P) iff there are a flow f on the chain graph (nodes src, snk, start b, edge a b; arcs src->snk, src->start b, start a->edge a b if X_a < X_b and Y_b < Y_a, edge a b->edge b c if the same for (b,c) and cross(a,b,c) > 0, start b->snk, edge a b->snk) and g with y = sum_e f_e 1_{Out e} + g, 0 <= g <= sum_e f_e 1_{Bnd e}. The slabs are defined with exact order and cross-product tests: leftOut b = {q != b : X_q < X_b or (X_q = X_b and Y_q < Y_b)}, leftBnd b = {q != b : X_q = X_b, Y_b <= Y_q}, edgeOut a b = {q != b : X_a < X_q <= X_b, cross(a,b,q) < 0}, edgeBnd (cross = 0), rightOut b = {X_q > X_b, Y_q < Y_b}, rightBnd (Y_q = Y_b). Duplicated points (equal coordinates, different index) and collinear triples are therefore covered by the formal statement. planar.py implements exactly these sets with exact Fractions (checked line by line against the Lean definitions above). Independent check of the implementation against the DEFINITION (brute-force family of weakly reachable sets, LP over their indicators): 2600 random planar sets with many duplicates/collinear/aligned points (1360 with duplicate points): 0 mismatches (t_fin1.py cone).
(F3) `PolyHardness.cube_mem_span` (FlowLP.lean): if O and B are disjoint, 0 <= z <= 1_B then 1_O + z is a nonnegative combination of 1_{O u B'}, B' subset of B. I use it in the equivalent form: if R_min subset R_max and v lies in the coordinate box [1_{R_min}, 1_{R_max}] then v is a convex combination of indicators 1_R, R_min subset R subset R_max.

**Lemma 1 (reachability as an interior condition, any d).** Let V be a finite subset of R^d with index set I, S a subset of I, K = conv{V_r : r not in S} + R^d_{>=0} (K = empty if S = I).
(a) (arbitrary point) For ANY point v of R^d (not necessarily a point of V): if v is not in int K then there is xi >= 0, xi != 0 with xi . (z - v) >= 0 for all z in K; conversely such a xi implies v not in int K. If v is not in K (K closed) there is xi >= 0, xi != 0 with xi.z > xi.v for all z in K.
(b) S is weakly reachable iff no V_t, t in S, lies in int K.
Proof. K is a closed convex up-set containing a translate of R^d_{>=0}; so K = closure(int K) and int K + R^d_{>=0} subset int K. (a) If xi works for v then K lies in the closed half space {xi.z >= xi.v}, whose interior misses v; so v is not interior to K. Conversely v not in the open convex set int K: separation gives xi != 0 with xi.z >= xi.v on int K, hence on K; xi >= 0 because K + R^d_{>=0} subset K (otherwise xi.z is unbounded below along a direction of R^d_{>=0}). For v not in the closed convex K use strict separation, xi >= 0 for the same reason. (b) is (a) applied to v = V_t together with the definition: the points of V outside S are exactly generators of K. QED
Part (a) is what is used for the corners L_t, U_t in Sec. 2, which are not generators of the sets K_k.

**Lemma 2 (diagonal exit).** For K as above (nonempty), K is closed under adding vectors >= 0 and z + s 1 lies in K for s large; for a segment z(s) = a + s(b - a), a <= b, s in [0,1]: {s : z(s) in K} is a closed up-interval [lambda,1] (or empty), {s : z(s) not in int K} is a closed down-interval [0,lambda°] (or empty). Both because K is closed and int K is open and both are up-sets and z(s) is coordinatewise nondecreasing.

## 2. Proof of Theorem 1

**(=>)** Let Q in box with y weakly solvable at Q. By (F1) y = sum_k lam_k 1_{S_k}, lam_k > 0, S_k weakly reachable at Q. Let T_k = complement of S_k and K_k = conv{Q_r : r in T_k} + R^2_{>=0} (empty if T_k empty); by Lemma 1 Q_t not in int K_k for t in S_k. Define S'_k subset of the index set of W by: a_t in S'_k iff L_t not in int K_k; b_t in S'_k iff U_t not in K_k (S'_k = everything if K_k empty).
S'_k is weakly reachable in W. Take v in S'_k. If v = a_t = L_t not in int K_k: Lemma 1 (applied to the set K_k and the point v, supporting hyperplane) gives xi >= 0, xi != 0, xi.z >= xi.v on K_k. Every point of W outside S'_k is either some L_r in int K_k or some U_r in K_k, so in K_k: xi.(z - v) >= 0 there. If v = b_t = U_t not in K_k: K_k closed convex up-set, strict separation gives xi >= 0, xi != 0 with xi.z > xi.v on K_k; same conclusion.
Put w = sum_k lam_k 1_{S'_k} (in C(W)). For t in S_k: Q_t not in int K_k and L_t <= Q_t; if L_t were in int K_k then Q_t in int K_k (int K up-set): so a_t in S'_k, hence w(a_t) >= sum_{k: t in S_k} lam_k = y_t. For t not in S_k: Q_t in K_k, U_t >= Q_t so U_t in K_k, b_t not in S'_k; hence w(b_t) <= sum_{k: t in S_k} lam_k = y_t.

**(<=)** Let w = sum_k m_k 1_{S_k}, m_k > 0, S_k weakly reachable in W, with sum_{k: a_t in S_k} m_k >= y_t >= sum_{k: b_t in S_k} m_k. Let K_k = conv(W \ S_k) + R^2_{>=0} (K_k empty if S_k is everything). By Lemma 1, a_t in S_k implies a_t not in int K_k; b_t not in S_k implies b_t in K_k (it is a generator).
Segment z_t(s) = L_t + s (U_t - L_t), s in [0,1] (a constant if L_t = U_t). Define on [0,1]
 hi_t(s) = sum_k m_k 1[z_t(s) not in int K_k],  lo_t(s) = sum_k m_k 1[z_t(s) not in K_k]
(with the convention: K_k empty contributes m_k to both). By Lemma 2 each indicator in hi_t is the indicator of a closed down-interval, hence upper semicontinuous and nonincreasing, so hi_t is usc, nonincreasing; each indicator in lo_t is that of the complement of a closed up-interval, an open-from-the-right down-interval, hence lower semicontinuous and nonincreasing: lo_t is lsc, nonincreasing; lo_t <= hi_t. Boundary values: hi_t(0) >= sum_{k: a_t in S_k} m_k >= y_t (a_t in S_k implies z_t(0) = a_t not in int K_k); lo_t(1) <= sum_{k: b_t in S_k} m_k <= y_t (z_t(1) = b_t not in K_k implies b_t in S_k, because points outside S_k lie in K_k).
Let s* = max{ s in [0,1] : hi_t(s) >= y_t } (exists: nonempty, closed by usc). Claim lo_t(s*) <= y_t. If s* = 1 this is lo_t(1) <= y_t. If s* < 1 then hi_t(s) < y_t for s in (s*,1], so lo_t(s) <= hi_t(s) < y_t there, and lsc gives lo_t(s*) <= liminf_{s -> s*+} lo_t(s) <= y_t. Hence
 lo_t(s*) <= y_t <= hi_t(s*).
Set Q_t = z_t(s*) in box_t, Q = (Q_t). For each k put R_min,k = {t : Q_t not in K_k}, R_max,k = {t : Q_t not in int K_k}; R_min,k subset R_max,k, and by definition sum_k m_k 1_{R_min,k}(t) = lo_t(s*) <= y_t <= hi_t(s*) = sum_k m_k 1_{R_max,k}(t).
Every R with R_min,k subset R subset R_max,k is weakly reachable at Q: for t in R, Q_t not in int K_k, Lemma 1 gives xi >= 0, xi != 0 with xi.(z - Q_t) >= 0 on K_k; every r not in R has r not in R_min,k, so Q_r in K_k, and xi.(Q_r - Q_t) >= 0. (If K_k is empty R = everything.)
The coordinatewise interval [sum m_k 1_{R_min,k}, sum m_k 1_{R_max,k}] is the Minkowski sum of the boxes m_k [1_{R_min,k}, 1_{R_max,k}]; so y = sum_k m_k v_k with v_k in [1_{R_min,k}, 1_{R_max,k}]. By (F3) each v_k is a convex combination of indicators of sets R between R_min,k and R_max,k, all weakly reachable at Q. So y is in the weakly reachable cone of Q, and by (F1) (d = 2, Q > 0, y >= 0) y is weakly solvable at Q. QED
No genericity, no enlargement, no compactness is used. Zero-width boxes are segments of length 0 and fall under the same proof.

## 3. Algorithm and complexity (Theorems 2 and 3)

Input L, U, y (rationals, bit length b each). 
1. W = (L,U), n = 2T. Chain graph of W (planar.chain_graph; exact rational order and cross-product tests, O(n^3) tests; a cross product of three input points has numerator and denominator of at most 12 b + O(1) bits). Number of nodes: n + E + 2 where E <= C(n,2) is the number of pairs with X_a < X_b, Y_b < Y_a; number of arcs <= 1 + 2n + 2E + C(n,3) (a chain a->b->c is determined by its three points since X increases) = (4/3) T^3 + O(T^2).
2. By (F2) and Theorem 1, BOX <=> feasibility of: f >= 0 on arcs, conservation at the E + n internal nodes, g >= 0, sigma >= 0, g_q <= sum_{arcs with q in Bnd} f, and for each t: (sum_{arcs, a_t in Out} f) + g_{a_t} - sigma_t = y_t, (sum_{arcs, b_t in Out} f) + g_{b_t} + sigma'_t = y_t (sigma' >= 0). Coefficients are in {0, +1, -1}, right-hand sides are 0 and y_t. Variables: arcs + 4T + ... = O(T^3); rows O(T^2). Feasibility of a rational LP is solvable exactly by a polynomial-time algorithm (ellipsoid method of Khachiyan, or an interior-point method followed by rounding to a vertex), in time polynomial in the number of variables and rows and in the bit length of the data; here that is polynomial in T and b. The chain-graph data and the LP data contain only numbers of the input size (0, +-1, and the y_t). The code (exactbox.decide_closed) uses an exact Bland simplex on Fractions purely as an implementation; Bland's rule is not polynomial in the worst case and is not part of the complexity claim.
3. Witness (Theorem 3). From a rational basic solution decompose the flow into source-sink paths with masses; each path gives Out(path) and Bnd(path); split the g-part as follows. For q in W let load_q = sum_e f_e [q in Bnd e] and phi_q = g_q / load_q in [0,1] (phi_q = 0 if load_q = 0; g_q <= load_q is a constraint of the LP). For a path pi with mass m_pi, Out(pi) and B = Bnd(pi) are disjoint, and by `isReachableB_iff_path` every set Out(pi) u B' with B' subset B is weakly reachable. Summing over paths, sum_pi m_pi (1_{Out(pi)} + sum_{q in B(pi)} phi_q 1_q) = sum_e f_e 1_{Out e} + sum_q phi_q load_q 1_q = sum_e f_e 1_{Out e} + g = w. For one path, let c_1 > ... > c_r > 0 be the distinct positive values of phi on B and c_{r+1} = 0; then 1_{Out} + sum_q phi_q 1_q = (1 - c_1) 1_{Out} + sum_{j=1..r} (c_j - c_{j+1}) 1_{Out u {q in B : phi_q >= c_j}} (this is the cube lemma `cube_mem_span` in its simplest, nested, form: the level sets of phi on B form a chain). All sets occurring are weakly reachable and the masses m_pi (1 - c_1), m_pi (c_j - c_{j+1}) are >= 0 rationals. This is exactly what planar.certify does and what exactbox.sets_and_masses / construct_closed implement; construct_closed re-verifies every set with the independent exact check planar.is_reachable and asserts that the resulting masses still satisfy w(a_t) >= y_t >= w(b_t). Then K_k = conv(W \ S_k) + R^2_{>=0} has the exact facet description {z : xi_j.z >= c_j}, xi_j in {(1,0),(0,1)} or (Y_b - Y_a, X_a - X_b) perpendicular to a hull edge with xi >= 0. For the segment z_t(s): s -> xi_j.z_t(s) is nondecreasing, so {s : z_t(s) not in int K_k} = [0, lambda°_k] with lambda°_k = max_j (c_j - xi_j.L_t) / (xi_j.(U_t - L_t)) (terms with xi_j.(U_t-L_t) = 0 are +infinity if xi_j.L_t <= c_j, -infinity otherwise; K_k empty gives +infinity); cap at 1. Then s*_t = max{ c : c in {min(1,lambda°_k) : lambda°_k >= 0}, sum_{k: min(1,lambda°_k) >= c} m_k >= y_t } and s*_t = 1 if y_t = 0. Q_t = L_t + s*_t (U_t - L_t). Each s*_t is one of the rational numbers min(1, lambda°_k) (a ratio of integers of at most 24 b bits each, where b is the maximal bit length of a numerator or denominator of an entry of L, U, for b >= 4: the facet normal xi has entries with <= 2b+1 bits, c_j = xi.V is a sum of two products with numerator and denominator <= 6b+2 bits, the numerator c_j - xi.L_t has <= 12b+2 bits, the denominator xi.(U_t-L_t) <= 8b+2 bits, the quotient <= 20b+4 bits); the masses m_k only decide which one. Q is rational of polynomial bit length, lies in [L,U], and by Sec. 2 y is weakly solvable at Q. The code (exactbox.construct_closed) also certifies this exactly (planar.certify + check_certificate: rational combination of weakly reachable sets of Q reproducing y).
(Remark: the s* of the proof is exactly this maximum: hi_t(s) = sum_k m_k 1[s <= lambda°_k].)

## 4. Theorem 4 (dominance only, any d, arbitrary boxes)

Necessity: Q_{s,i} <= Q_{t,i} gives L_{s,i} <= Q_{s,i} <= Q_{t,i} <= U_{t,i}.
Sufficiency. w_{t,i} = U_{t,i} - L_{t,i}. b_i(p,t) = (L_{p,i} - L_{t,i}) / w_{t,i} if w_{t,i} > 0; -infinity if w_{t,i} = 0 and L_{p,i} <= L_{t,i}; +infinity if w_{t,i} = 0 and L_{p,i} > L_{t,i}; beta(p,t) = min_i b_i(p,t). In all cases b_i(p,t) <= 1 iff L_{p,i} <= U_{t,i}, so the hypothesis says beta(p,t) <= 1 whenever y_p > y_t. Witness: tau_t = min(1, max(0, max_{p: y_p > y_t} beta(p,t))) (0 if no heavier p), Q_t = L_t + tau_t (U_t - L_t).
Claim 1: either tau_s = 0 and Q_s = L_s, or Q_s <= L_p for some p heavier than s. If tau_s > 0 take p heavier with beta(p,s) = tau_s (tau_s <= 1 and beta <= 1). All b_i(p,s) >= tau_s > 0: for w_{s,i} > 0 this is L_{p,i} - L_{s,i} >= tau_s w_{s,i}; for w_{s,i} = 0 it forces b_i = +infinity (not -infinity since tau_s > 0), so L_{p,i} > L_{s,i} = Q_{s,i}.
Claim 2: y_p > y_t implies some i with L_{p,i} <= Q_{t,i}: take i with b_i(p,t) = beta(p,t) <= 1; if w_{t,i} > 0, beta <= max(0,beta) <= tau_t gives L_{p,i} <= L_{t,i} + tau_t w_{t,i}; if w_{t,i} = 0 then b_i = -infinity: L_{p,i} <= L_{t,i} = Q_{t,i}.
Now y_s > y_t. If tau_s = 0: Claim 2 with p = s gives i with Q_{s,i} = L_{s,i} <= Q_{t,i}. If tau_s > 0: p from Claim 1 is heavier than t as well; Claim 2 gives i with L_{p,i} <= Q_{t,i}, and Q_{s,i} <= L_{p,i}. QED. (Uniform boxes, weighted boxes r_ti = lam w_ti: optimal lam = max_{y_s>y_t} min_i (a_si - a_ti)/(w_si + w_ti).)

## 5. Theorem 5 (rho_inf as a critical value)

Let the boxes be L(kappa) = P/kappa, U(kappa) = kappa P (or any L(kappa) nonincreasing, U(kappa) nondecreasing, continuous). BOX is monotone in kappa, and the set of kappa with BOX is closed (compactness of the boxes plus closedness of {Q : WeakSolvable Q y}), so kappa* = min{kappa >= 1 : BOX(kappa)} exists. By Theorem 1 BOX(kappa) <=> LP(W_kappa). The LP depends on W_kappa only through the chain-graph data, i.e. the signs of coordinate differences and of cross(a,b,q) over triples of corners. For corners P_t/kappa and kappa P_t: a coordinate difference changes sign only at kappa^2 = P_{s,i}/P_{t,i}; kappa^2 * cross is a polynomial in kappa of degree <= 4. Hence there are at most 2 C(T,2) + 4 C(2T,3) = O(T^3) critical values, the truth of LP is constant on each open interval between consecutive ones, and since LP is false below kappa* and true at kappa*, kappa* is a critical value (or 1). Algorithm: compute the critical values (crit.py), sort, binary search with exact LP at each test value (critical values themselves and midpoints; at critical values use exact algebraic-number comparison, or rational bracketing plus the exactness of LP at the closed corners). Independent exact test (t_fin3.py, exact closed-box LP at rational kappa, boxes [P/kappa, kappa P], P in quarter-integers, T 3..4, kappa* > 1): for 59 instances, the LP truth at the midpoints of all consecutive critical intervals is monotone (False..False, True..True) with its transition at one critical value kc, and BOX is false at kc(1-1e-9) and true at kc(1+1e-11) in all 59 (kc is usually irrational, so exact equality at kc cannot be tested in rationals; the bracket is the test). Earlier bisection test: kappa* equals a critical value to 1e-7 in 28/28.

## 7. Lean-friendly statement (not formalized)

```lean
noncomputable def corners (L U : Fin T -> Fin 2 -> R) : Fin (T + T) -> Fin 2 -> R := Fin.append L U
def CornerFeasible (L U) (y) : Prop :=
  exists w in indicatorCone (weakReachableSpectra (corners L U)),
    (forall t, y t <= w (Fin.castAdd T t)) /\ (forall t, w (Fin.natAdd T t) <= y t)
theorem box_iff (hL : forall t, L t in orthant 2) (hLU : L <= U) (hy : forall t, 0 <= y t) :
    (exists Q, L <= Q /\ Q <= U /\ WeakSolvable Q y) <-> CornerFeasible L U y
```
Proof pieces: `lemma1` (IsWeakReachable iff not in interior), `box_to_corners` (Sec. 2 =>), `corners_to_box` (Sec. 2 <=, with `cube_mem_span` and `weakSolvable_iff`).
For the perturbation function: `pert p q <= e <-> p/(1+e) <= q /\ q <= p*(1+e)` (p, q > 0, e >= 0), so BOX(P,y,e) is box_iff with L = P/(1+e), U = (1+e) P.
