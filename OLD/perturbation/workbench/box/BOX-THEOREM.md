# BOX for an arbitrary box: theorem, algorithm, proofs (d = 2; dominance part for all d)

Data: rational L, U in R^{T x 2}_{>0} with L <= U coordinatewise (zero-width coordinates and L = U allowed), y in R^T_{>=0} rational. box_t = [L_t, U_t].
BOX(L,U,y): exists Q, L <= Q <= U, with y weakly solvable at Q (`WeakSolvable Q y`).
Notation: 1 = (1,1); z << z' means strictly smaller in both coordinates. For delta in (0, min L) the enlarged box is E_delta = [L - delta 1, U + delta 1] (positive). Its corner configuration is
W_delta = (a_1..a_T, b_1..b_T), a_t = L_t - delta 1, b_t = U_t + delta 1 (2T points of R^2_{>0}).
C(W) = cone generated by the indicators of the weakly reachable subsets of W (`indicatorCone (weakReachableSpectra W)`). By `weakSolvable_iff` (d >= 2, W >= 0, y >= 0): WeakSolvable W w iff w in C(W).
LP(delta): exists w in C(W_delta) with w(a_t) >= y_t >= w(b_t) for all t.

## 0. Results

**Theorem A (exact decision).** Let N = common denominator of all entries of L, U, A = N * max entry, and
delta* = min( 1 / (2N(1 + 32 A^2)),  (min L)/2 ).
For every delta in (0, delta*]:  BOX(L,U,y)  <=>  LP(delta).
(The same equivalence holds for the closed box with zero-width coordinates and for fully fixed prices L = U = P, where it says: y weakly solvable at P iff LP(delta).)

**Theorem B (complexity).** LP(delta) with delta = delta* is a linear feasibility problem with <= n + n(n-1)/2 + 2 flow nodes and <= 1 + 2n + n(n-1) + C(n,3) arcs, n = 2T (so about (4/3) T^3 arc variables, 4T^2 rows), all constraint coefficients in {0, +-1}, right-hand sides y_t and 0. Hence BOX is decided in time polynomial in T and in the bit-size of (L, U, y) (delta* has O(T b) bits when entries have b bits). All intermediate numbers are rationals of polynomial size (exact chain graph by rational arithmetic; exact LP by Khachiyan's method or any exact rational simplex).

**Theorem C (construction).** If BOX(L,U,y) holds then for every rational eps > 0 an explicit rational Q in E_eps with y weakly solvable at Q is computed in polynomial time (exact certificate: a rational combination of weakly reachable sets, checked by planar.certify). A witness Q in the closed box exists (Theorem A), is the limit eps -> 0 of these, and need not be rational; I do not claim a rational closed-box witness.

**Theorem D (dominance only, any d, arbitrary boxes).** `NoDom Q y := forall s t, y_t < y_s -> exists i, Q_{s,i} <= Q_{t,i}`. For L <= U in R^{T x d}: exists Q in [L,U] with NoDom Q y  <=>  for all s,t with y_t < y_s there is i with L_{s,i} <= U_{t,i}. Explicit witness below; O(d T^2) arithmetic operations.

## 1. Proof of Theorem D

Necessity: Q_{s,i} <= Q_{t,i} gives L_{s,i} <= Q_{s,i} <= Q_{t,i} <= U_{t,i}.
Sufficiency. Put w_{t,i} = U_{t,i} - L_{t,i} >= 0. For p, t define the ratios
b_i(p,t) = (L_{p,i} - L_{t,i}) / w_{t,i} if w_{t,i} > 0;  b_i(p,t) = -infinity if w_{t,i} = 0 and L_{p,i} <= L_{t,i};  b_i(p,t) = +infinity if w_{t,i} = 0 and L_{p,i} > L_{t,i};
beta(p,t) = min_i b_i(p,t). In all three cases: b_i(p,t) <= 1 iff L_{p,i} <= U_{t,i}, hence the hypothesis says beta(p,t) <= 1 whenever y_p > y_t.
Witness: tau_t = min(1, max(0, max_{p: y_p>y_t} beta(p,t))) (0 if no heavier p), Q_t = L_t + tau_t (U_t - L_t) in box_t.
Claim 1: for every s there is p with Q_s <= L_p coordinatewise, or Q_s = L_s. If tau_s = 0 then Q_s = L_s. If tau_s > 0, let p be heavier than s with beta(p,s) = tau_s (tau_s <= 1 and beta <= 1, so tau_s = beta(p,s) > 0). Then every b_i(p,s) >= tau_s > 0. For w_{s,i} > 0: L_{p,i} - L_{s,i} >= tau_s w_{s,i}, i.e. Q_{s,i} <= L_{p,i}. For w_{s,i} = 0: b_i = +infinity (it cannot be -infinity since tau_s > 0), so L_{p,i} > L_{s,i} = Q_{s,i}. So Q_s <= L_p.
Claim 2: if y_p > y_t then some i has L_{p,i} <= Q_{t,i}. Take i with b_i(p,t) = beta(p,t) <= 1 (finite or -infinity). If w_{t,i} > 0: beta <= max(0,beta) <= tau_t gives L_{p,i} <= L_{t,i} + tau_t w_{t,i} = Q_{t,i}. If w_{t,i} = 0: b_i = -infinity means L_{p,i} <= L_{t,i} = Q_{t,i}.
Now let y_s > y_t. Case tau_s = 0: Q_s = L_s and Claim 2 with p = s gives i with Q_{s,i} = L_{s,i} <= Q_{t,i}. Case tau_s > 0: p from Claim 1 is heavier than s, hence than t; Claim 2 gives i with L_{p,i} <= Q_{t,i}, and Q_{s,i} <= L_{p,i}. QED. (Zero-width coordinates and fixed boxes are covered; ties allowed.) Optimal scaling for a family of boxes r_ti = lam w_ti is lam = max over y_s>y_t of min_i (a_si - a_ti)/(w_si+w_ti).

## 2. Proof of Theorem A

**Lemma 1 (weak reachability as an interior condition, any d).** S subset of a finite set W of R^d is weakly reachable iff no v in S lies in int K, K = conv(W\S) + R^d_{>=0} (K empty if S = W).
Proof. If xi >= 0, xi != 0 works for v (xi.(z - v) >= 0 on W\S), then K lies in the closed half space {xi.z >= xi.v}, so v is not interior. Conversely v not in int K, K convex: there is xi != 0 with xi.z >= xi.v on int K, hence on K (K contains a translate of R^d_{>=0}, so K is the closure of its interior); K + R^d_{>=0} = K forces xi >= 0. QED

**Lemma 2 (necessity, no genericity).** BOX(L,U,y) implies LP(delta) for every delta in (0, min L).
Proof. Let Q in box, y = sum_k lam_k 1_{S_k} with S_k weakly reachable at Q (weakSolvable_iff). Put T_k = complement of S_k, K_k = conv{Q_r : r in T_k} + R^2_{>=0} (empty if T_k empty); by Lemma 1, Q_t is not in int K_k for t in S_k. Define S'_k = {v in W_delta : v not in K_k}. S'_k is weakly reachable in W_delta: for v not in K_k strict separation gives xi >= 0, xi != 0, xi.z > xi.v on K_k, and W_delta \ S'_k is in K_k. Let w = sum lam_k 1_{S'_k}. If t in S_k, a_t << Q_t, so a_t is not in K_k (else Q_t in int K_k): a_t in S'_k. If t not in S_k then Q_t in K_k and b_t >> Q_t gives b_t in K_k: b_t not in S'_k. Hence w(a_t) >= sum_{k: t in S_k} lam_k = y_t and w(b_t) <= y_t. QED

**Lemma 3 (sufficiency with room, no genericity).** LP(delta) implies BOX(E_eps) for every eps in (delta, min L), i.e. there is Q in E_eps with y weakly solvable at Q.
Proof. Write w = sum_k m_k 1_{S_k}, m_k > 0, S_k weakly reachable in W = W_delta, with sum_{k: a_t in S_k} m_k >= y_t >= sum_{k: b_t in S_k} m_k. Let K_k = conv(W\S_k) + R^2_{>=0}; for K_k nonempty let s_k(z) = min{s : z + s 1 in K_k} (finite, convex, hence continuous; z + s 1 in K_k iff s >= s_k(z)). Then: (a) if z' >= z + g 1 then s_k(z') <= s_k(z) - g (up-set). (b) v in S_k implies s_k(v) >= 0 (if s_k(v) < 0 then v >= (v + s 1) + |s| 1 with v+s 1 in K, so v in int K, contradicting Lemma 1), and z in W\S_k implies s_k(z) <= 0. For K_k empty (S_k = W) put theta_k = 1.
Let g = eps - delta > 0, a'_t = L_t - eps 1 = a_t - g 1, b'_t = U_t + eps 1 = b_t + g 1. By (a),(b): a_t in S_k => s_k(a'_t) >= g; b_t not in S_k => s_k(b'_t) <= -g. Put theta_k = min(1, max(0, s_k/g)), phi = sum_k m_k theta_k (continuous). Then phi(a'_t) >= sum_{k: a_t in S_k} m_k >= y_t and phi(b'_t) <= sum_{k: b_t in S_k} m_k <= y_t. The segment [a'_t, b'_t] lies in E_eps and is connected; by the intermediate value theorem pick Q_t on it with phi(Q_t) = y_t.
Weak solvability at Q: theta_k(z) = integral_0^1 1[z + u g 1 not in K_k] du (since s_k(z) > u g iff z + u g 1 not in K_k). For fixed (k,u) let R = {t : Q_t + u g 1 not in K_k}. For t in R and r not in R, strict separation of the point Q_t + u g 1 from the closed convex up-set K_k gives xi >= 0, xi != 0 with xi.(Q_r + u g 1) >= c > xi.(Q_t + u g 1), so xi.(Q_r - Q_t) > 0: R is weakly reachable at Q. As Q is finite, u -> R takes finitely many values, so y_t = phi(Q_t) = sum_k m_k integral 1[t in R_{k,u}] du is a nonnegative combination of indicators of weakly reachable sets: y in C(Q). By weakSolvable_iff, y is weakly solvable at Q. QED

**Lemma 4 (combinatorial type).** The flow LP system characterizing `y in C(W)` for 2D point sets (poly-hardness FlowLP / planar.py: nodes, arcs, Out/Bnd sets of the chain graph) depends on W only through the signs of: x_a - x_b, y_a - y_b, and cross(a,b,q) = (x_b-x_a)(y_q-y_a) - (y_b-y_a)(x_q-x_a), over points a,b,q of W (these are all the predicates in `down`, `left_slab`, `edge_slab`, `right_slab`, `chain_graph`). y enters only the right-hand side. For W_delta each such quantity is a polynomial in delta of degree <= 2 with rational coefficients. If none changes sign (or becomes 0 from non-zero) on an interval, the chain graph is the same, so LP(delta) has the same truth value there.
**Lemma 5 (root separation).** Write each entry c = a/N with integer 0 < a <= A and delta = eta/N. Then N * (coordinate difference) = integer polynomial in eta of degree <= 1 with coefficients <= 2A, and N^2 * cross is an integer polynomial of degree <= 2 with coefficients <= 8(A+1)^2 <= 32 A^2 =: H (A >= 1). A non-zero integer polynomial with coefficients bounded by H has no root eta with 0 < eta < 1/(1+H) (Cauchy's lower bound: lowest non-zero coefficient c_m has |c_m| >= 1; roots satisfy |eta| >= |c_m| / (|c_m| + max|c_i|)). Hence none of the polynomials of Lemma 4 vanishes or changes sign for 0 < delta < 1/(N(1+H)), in particular on (0, delta*].
**Proof of Theorem A.** (=>) Lemma 2 with delta in (0, delta*]. (<=) By Lemmas 4, 5, LP(delta') holds for all delta' in (0, delta*]. By Lemma 3, for every eps in (0, delta*] pick delta' = eps/2: BOX(E_eps) holds. Take eps_n -> 0 and Q^n in E_{eps_n} with y weakly solvable at Q^n; the points stay in a compact set, a subsequence converges to Q in box (the box is closed and the E_eps decrease to it), and {Q : WeakSolvable Q y} is closed (`WeakSolvable` is membership in a closure). So Q in box with y weakly solvable. QED
Remark: no general position and no non-degeneracy of the box is used. Zero-width boxes appear only through E_delta, which is a genuine rectangle.

## 3. Proof of Theorem B and C (algorithm)

Algorithm DECIDE(L,U,y): (1) compute delta* exactly; (2) W = W_{delta*} (rationals); (3) chain graph (planar.chain_graph, exact Fractions: O(n^3) cross products); (4) feasibility of the system: flow f >= 0 on arcs with node conservation, g >= 0, point rows sum_{arcs: q in Out} f + g_q - sigma_q = y_q (rows a_t), + sigma_q = y_t (rows b_t), sigma >= 0, g_q <= sum_{arcs: q in Bnd} f. This is exactly: exists w = (flow part + g) in C(W) (FlowLP: y in cone iff exists flow with y = sum_e f_e 1_{Out e} + g, 0 <= g <= sum f_e 1_{Bnd e}) with w(a_t) >= y_t >= w(b_t). Exact rational LP: polynomial time. Size: at most C(n,2) + n + 2 nodes, and arcs: 1 + 2n (start/end) + 2 C(n,2) (start->edge, edge->sink) + #{chains a->b->c} <= C(n,3), n = 2T.
CONSTRUCT(eps): choose delta = eps/2 (or delta* if eps > 2 delta*, any rational delta in (0,delta*] with delta < eps works); solve the LP exactly (basic solution, rational); decompose the flow into source-sink paths (masses m, sets Out(path)); split boundary parts g by the common fraction g_q / load_q (nested sets, as planar.certify), keeping only sets that planar.is_reachable confirms; then Lemma 3: K_k facets by exact 2D hull, s_k = max over facets (c_j - xi_j.z)/(xi_j.1), theta_k = clip(s_k/g); along each segment [a'_t, b'_t] phi is piecewise linear with breakpoints computed exactly (pairwise intersections of the affine pieces, and where they cross 0 and g); the root of phi = y_t is a rational. Output Q rational, in E_eps; certificate checked exactly (planar.certify + check_certificate). Bit-size of Q polynomial: it is the solution of a linear equation whose data are basic-LP rationals.
Closed-box witness: by Theorem A it exists; computing it is a real-algebraic problem (tightness can force quadratic equations, since weak reachability of three points is a quadratic condition), so only the eps-approximants are given.

## 4. Remark on the closed LP (not claimed as theorem)
Lemma 2's proof also works with W_0 (delta = 0) and "S'_k = {a_t not in int K_k} u {b_t not in K_k}": BOX => LP(0) (closed corners) is proved. The converse LP(0) => BOX is not proved; it was observed in 250 + 300 exact tests (including L = U) with no disagreement.
